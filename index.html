Cómo usar la experiencia

  1. Presiona “Iniciar AR”
  2. Permite el acceso a la cámara
  3. Apunta a una superficie plana (mesa, piso)
  4. Toca la pantalla para colocar la caverna
  5. Explora tocando los objetos

Requiere HTTPS, cámara y un dispositivo compatible con WebXR + ARCore (Android recomendado).
